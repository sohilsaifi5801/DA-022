# Road Accident Pattern Analysis in India

This project analyses road accident statistics in India using data published by the Ministry of Road Transport and Highways (MoRTH).

## Objectives
- Analyse road accidents by time and severity.
- Compare accidents across weather conditions and road categories.
- Study monthly, annual and rural-urban trends.
- Present findings using charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
- `data/` – Dataset files
- `src/` – Python scripts
- `notebooks/` – Jupyter Notebook
- `visualizations/` – Charts
- `reports/` – Analysis results
- `docs/` – Data source information

## Data Source
Ministry of Road Transport and Highways (MoRTH), Government of India.

[Road Accidents in India – 2023](https://morth.nic.in/sites/default/files/Road-Accident-in-India-2023-Publications.pdf)

**Note:** The project uses aggregated government statistics, not individual accident records. Data coverage varies by category and year.

## How to Run
1. Install the required libraries using `pip install -r requirements.txt`.
2. Run `python src/06_run_all.py`.
3. Open the notebook in Jupyter Notebook or Google Colab.

## Conclusion
The project provides a descriptive analysis of road accident patterns in India using published government statistics.
